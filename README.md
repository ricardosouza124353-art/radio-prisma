# Rádio Prisma Web

Bem-vindo ao repositório oficial do site da **Rádio Prisma Web**!  
Aqui você encontra o código do site que transmite nossa programação ao vivo 24h.

## 🎧 Player ao vivo
O site possui um player integrado para você ouvir a rádio diretamente pelo navegador.

## 📱 Compatível com dispositivos móveis
O site foi desenvolvido para funcionar bem em celulares, tablets e computadores.

## 🚀 Tecnologias usadas
- HTML
- CSS
- JavaScript

## 📡 Transmissão ao vivo
A rádio transmite música variada, notícias e entretenimento 24 horas por dia.
